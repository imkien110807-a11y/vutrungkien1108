# My Portfolio

Mở `index.html` bằng trình duyệt (hoặc dùng Live Server / Preview trong Antigravity).

## Cấu trúc
- `index.html`   : nội dung trang
- `css/style.css`: hiệu ứng, menu thả xuống, khoảng cách 3 dòng
- `js/main.js`   : cuộn mượt, hiện dần theo cuộn, link các bài

## Gắn trang riêng cho từng bài
Mở `js/main.js`, điền URL vào bảng `LESSON_PAGES`, ví dụ `bai1: 'bai-1.html'`.
Để trống thì bấm vào bài sẽ mở nội dung ngay trong trang.

Lưu ý: cần có Internet để tải Tailwind CSS và Google Fonts (dùng CDN).
